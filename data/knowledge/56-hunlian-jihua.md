## 中级训练者周计划模板：如何把力量、有氧和柔韧拧成一股绳

很多中级训练者卡在瓶颈期，不是因为练得不够狠，而是三种训练互相“打架”。力量训练后腿酸，第二天跑步跑不动；有氧做太多，力量举铁时没力气。其实只要安排好顺序和频率，三者可以互相促进。下面给你三个可直接套用的周计划模板，以及怎么根据身体信号调整。

### 一、同一天内训练顺序的铁律

不管你的目标是什么，只要力量和柔韧、有氧放在同一次训练里，顺序必须是：**力量 → 有氧 → 拉伸**。原因很简单：力量训练需要神经系统高度兴奋，如果你先跑5公里再举铁，神经疲劳会让你核心不稳、动作变形，增加受伤风险。有氧放在力量之后，正好利用肌肉充血和体温升高，燃脂效率更高。最后的柔韧拉伸则帮助肌肉恢复弹性。

### 二、三个目标对应的周计划模板

#### 模板1：增肌优先（力量为主，有氧辅助）
- **周一**：力量训练（胸+三头） → 6小时后做20分钟低强度有氧（快走或椭圆机） → 睡前10分钟拉伸
- **周二**：力量训练（背+二头） → 单独做15分钟泡沫轴放松
- **周三**：休息或30分钟慢跑（心率控制在120-140） → 全身拉伸
- **周四**：力量训练（腿+肩） → 20分钟爬坡走
- **周五**：力量训练（全身辅助动作） → 10分钟拉伸
- **周六**：40分钟中等强度有氧（心率140-160） → 拉伸
- **周日**：完全休息

**关键点**：力量日和有氧日尽量隔开6小时以上，避免影响肌肉恢复。有氧强度控制在“能说话但有点喘”的程度，不要冲刺跑。

#### 模板2：跑步优先（耐力为主，力量维护）
- **周一**：60分钟节奏跑（心率150-165） → 10分钟拉伸
- **周二**：30分钟力量训练（深蹲、硬拉、划船，每组8-12次，重量为1RM的60%） → 15分钟拉伸
- **周三**：45分钟轻松跑（心率120-135） → 拉伸
- **周四**：休息或20分钟瑜伽（侧重髋屈肌和腘绳肌拉伸）
- **周五**：40分钟间歇跑（如400米×6组，组间休息1分钟） → 力量训练（仅做上肢推拉）
- **周六**：90分钟长距离慢跑（心率130-145） → 泡沫轴放松
- **周日**：完全休息

**关键点**：力量训练只需维持肌肉量，不要做到力竭。每次力量训练控制在30分钟内，组间休息短一些（45秒）。

#### 模板3：综合健康均衡版（三不误）
- **周一**：力量训练（全身，每个部位2个动作，共6个动作） → 20分钟有氧（划船机或跳绳） → 10分钟拉伸
- **周二**：45分钟瑜伽（侧重力量和柔韧结合，如流瑜伽）
- **周三**：40分钟中等强度有氧（骑行或游泳） → 15分钟拉伸
- **周四**：力量训练（同上，换动作顺序） → 20分钟有氧 → 拉伸
- **周五**：30分钟轻松跑 + 15分钟动态拉伸
- **周六**：户外徒步或球类运动（自然融合三种训练）
- **周日**：休息或10分钟冥想呼吸

**关键点**：每次训练总时长控制在60-75分钟，力量和有氧在同一天时，力量先做，有氧不超过25分钟。

### 三、如何用恢复信号调整计划

别死守计划。如果出现以下信号，说明你需要降低强度或改做恢复日：
- **HRV（心率变异性）** 连续下降超过10%（可用手表监测）→ 第二天改做拉伸或散步
- **静息心率** 比平时高5次/分钟以上 → 取消高强度训练，只做低强度有氧
- **肌肉酸痛持续超过72小时** → 说明力量训练强度太大，下次减少1-2组或降低5%重量

**具体操作**：每周日早晨测一次静息心率和HRV，如果两项都异常，周一就做“恢复日”——20分钟快走+全身拉伸+泡沫轴，不要做任何力量或高强度有氧。

---

### 核心要点

1. **顺序铁律**：同一次训练先力量（神经系统优先）→ 再有氧（利用充血）→ 最后拉伸（帮助恢复），不要颠倒。
2. **增肌者**：力量和有氧隔6小时以上或分不同天，有氧强度控制在心率120-140，每周不超过2次。
3. **跑者**：力量训练只做维持性（每组8-12次，1RM的60%），放在轻松跑日或间歇跑之后，不做到力竭。
4. **综合健康**：每周2-3次力量+2-3次有氧+2-3次柔韧，交替日进行，每次训练总时长不超过75分钟。
5. **随时调整**：HRV下降10%或静息心率上升5次/分钟时，立刻降强度做恢复日，别硬撑。
